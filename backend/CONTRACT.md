# WoundCoPilot next — shared implementation contract

New implementation, version 6.0.0. Root owns integration, server/core.py, db.py, identity.py, audit.py, providers.py, main.py, migration assembly, deployment and release. Clinical agent owns server/clinical.py, clinical_models.py, schemas.py, prompts/, tests/test_clinical.py. Commerce agent owns server/billing.py, billing_models.py, contact.py, tests/test_billing.py, legal content. Frontend agent owns frontend/ exclusively plus docs/DESIGN.md. Never modify another owner's files; send contract changes to root.

## Common backend

Python FastAPI, SQLAlchemy 2, Pydantic 2. server.db provides Base, SessionLocal, engine, get_db, utcnow(), uid(). server.core provides settings singleton. server.identity provides User, Workspace, Membership, LoginSession, current_user(request, db=Depends(get_db)) returning User, require_csrf(request, user=Depends(current_user)) and require_admin(user=Depends(current_user)). User has id,email,display_name,password_hash,workspace_id,is_platform_admin,is_active,profile(JSON),created_at. Workspace id/name; Membership user_id/workspace_id/role. current_user enforces membership, terms and session activity. server.audit.write_audit(db,user,action,resource_id,detail={}) stages event inside caller transaction. Every mutation depends require_csrf except signup/login/public contact/verified Stripe webhook.

API prefix /api/v1 added once by main to APIRouters. User object exposed: id,email,display_name,workspace_id,is_platform_admin,profile. GET /auth/session -> {user,csrf_token}; POST /auth/signup {email,password,display_name,workspace_name,accept_terms:true,terms_version:'2026-09-05',privacy_version:'2026-09-05'} -> same 201; POST /auth/login {email,password} -> same; POST /auth/logout; PATCH /auth/profile {display_name?,profile?}; GET /health, /config. Credentials cookies only; send X-CSRF-Token for mutations. Never expose provider secrets. Normal users cannot set is_platform_admin.

## Clinical API

GET/POST /patients -> list/object {id,display_name,external_ref,created_at}. GET/POST /patients/{id}/wounds -> {id,patient_id,label,location,laterality,wound_type}. GET /encounters -> list {id,patient_id,wound_id,title,status,revision,updated_at}; POST /encounters {patient_id,wound_id?,title?}. GET /encounters/{id} -> full {encounter,patient,wound,evidence:[],facts:[],documents:[],review,conflicts:[]}. PATCH /encounters/{id} {expected_revision,draft_data?,title?} -> encounter. Encounter has draft_data JSON, revision integer. No caller-supplied signed status.

POST /encounters/{id}/evidence JSON {kind:'typed'|'transcript'|'manual'|'measurement'|'result',text?,findings?:[{name,value}],consent?:boolean,wound_id?}, idempotency key header optional. -> {evidence,facts}. POST /encounters/{id}/upload multipart file, kind photo|document|audio, consent bool, duration_seconds? -> {evidence,facts,warnings}. All facts include {id:logical fact_id,revision,name,value,confirmation_state:'unconfirmed'|'confirmed'|'rejected',source_type,source_ref,source_quote?,wound_id,confirmed_by,confirmed_at}. Supported common names: wound_measurement value {length_cm,width_cm,depth_cm?}; wound_location {site,laterality}; pain {text}; exudate {text}; odour/undermining/tunnelling/periwound/perfusion_assessment/offloading_assessment/compression/treatment_performed/patient_education/narrative/vascular_test/lab/culture/imaging/history/allergy/medication/nutrition/mobility/infection_findings/fever/diabetes typed or {text}. Manual findings explicitly clinician-attested confirmed, AI suggestions always unconfirmed. Server validates structures. POST /facts/{id}/review {expected_revision,action:'confirm'|'edit'|'reject',value?} -> new current fact revision, preserving old revision. GET /facts/{id}/history -> list revisions.

POST /encounters/{id}/review {mode:'auto'|'fast'|'advanced'|'deep',use_ai?:bool} -> {gaps:[],warnings:[],conflicts:[],considerations:[],case_revision}; all deterministic first. POST /encounters/{id}/draft {template:'nursing'|'soap'|'sbar'|'handoff'|'referral',use_ai?:bool,mode?} -> {text,fact_snapshot,warnings,case_revision}. POST /encounters/{id}/documents {text,template,expected_revision,amends_id?,reason?} + Idempotency-Key -> document {id,text,content_hash,status,version,case_revision,signed_at,signed_by,amends_id}. Preserve exact text, no stripping. POST /documents/{id}/sign {content_hash,acknowledge_review:true,expected_case_revision} -> doc; signing atomic and cannot change text. New amendments allowed only as explicit new version with reason. GET /encounters/{id}/audit -> list safe events.

server.providers interface: async extract_text(text,kind) -> {facts:[{name,value,quote}],warnings,usage}; async analyze_media(data:bytes,mime:str,kind:str) same; async transcribe(data,mime,filename,duration_seconds=None) -> {text,segments,warnings,usage}; async draft_text(facts,template,mode) -> {text,usage}; async clinical_review(facts,mode) -> {considerations,usage}. Root adds keyword user/db/operation_id/context for metering once billing wired. Clinical agent initially call providers with user=user,db=db,encounter_id=id; usage recorded by provider layer. Local tests monkeypatch these functions. Providers disabled gracefully without key, with deterministic manual/documentation paths. No fake production inference. Server request-limit helpers in identity: check_rate(key,limit=60,window_seconds=60).

## Billing/public/admin API

GET /plans -> {plans:[{id,name,price_cad,credits,encounter_estimate}],topup:{price_cad,credits},currency:'CAD'}. Plans essential24.99/2500, plus34.99/5000, pro49.99/12000, power75/18000, topup8.99/1000. No trial credit unless explicitly configured. Manual entry/edit/save/sign always permitted. AI paid calls require active subscription and available funds except platform admin.

GET /billing -> {plan,status,balance_credits,reserved_credits,is_unlimited,history:[]}. POST /billing/checkout {plan:'essential'|'plus'|'pro'|'power'|'topup'} -> {url}; POST /billing/portal -> {url}; webhook /billing/webhook signature verified no CSRF. Billing exposes reserve(db,user,operation_id,estimated_micros,encounter_id,task), settle(db,user,operation_id,actual_micros,provider,model,usage,actual_cost_micros?), release(db,user,operation_id,reason). Integer microUSD = milli-credit; 1000 units = 1 credit. Explicit price registry version; no floating point ledger. All idempotency scoped and payload checked. Admin skips quota but records costs. Usage may contain attempts bounded and failures accounted.

POST /contact {name,email,organization?,role?,team_size?,subject?,message,type:'support'|'business'} -> {id,status:'received'}; validated anti-spam no PHI request. GET /admin/overview and /admin/contacts -> admin only; PATCH /admin/contacts/{id} {status}; no automatic external messages. GET /legal/privacy, /legal/terms -> {version,title,content,requires_legal_review:true}. Config identifies launch approvals pending accurately; do not invent business address/legal name.
