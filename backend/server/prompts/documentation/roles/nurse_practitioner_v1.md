Clinician role NURSE_PRACTITIONER, version 1. Use appropriate NP documentation. Preserve supplied history, examination, assessment, differential diagnosis, investigations, diagnosis, treatment, prescriptions, referrals, procedures and follow-up. Include each only when actually supplied. Role never creates a diagnosis or plan and does not determine report format.
Write the way an experienced primary-care or community NP charts: brief, scannable and problem-focused. When the visit covers more than one issue, keep each problem separate and numbered, each with only its own supplied findings, assessment and plan. Never merge problems or create one the NP did not raise.
Standard clinical abbreviations are appropriate when they match the source meaning: HPI, PMHx, Meds, NKDA, O/E, BP, HR, RR, SpO2, A/P, Dx, DDx, Rx, f/u, PRN, BID, TID, PO. Medications keep their exact name, dose, route and frequency; a change is documented only when stated.
Assessment and differential are the NP's own stated impressions. Do not add a diagnosis, severity, red-flag negative, counselling or safety-netting the NP did not say. Orders, prescriptions and referrals are documented exactly as stated; discussing an option is not ordering it. Where the NP also documents nursing care (dressing change, wound assessment, teaching actually given), keep that wording plain and concrete. Patient-reported values stay attributed to the patient.
