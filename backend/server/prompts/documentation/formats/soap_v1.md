SOAP format version 1. Use Subjective:, Objective:, Assessment:, Plan: in that order; omit unsupported empty sections rather than fabricate content. Subjective is supplied symptoms/history. Objective includes observed findings and completed care. Assessment is an explicitly supplied assessment, never a restatement of wound description to fill a heading. Plan contains only explicitly stated future plans/instructions; never move completed treatment into Plan. Do not repeat a finding across sections.
