SOAP format version 1. Use Subjective:, Objective:, Assessment:, Plan: in that order, each heading on its own line with its content on the next line (the same layout every time); omit unsupported empty sections rather than fabricate content. Subjective is supplied symptoms/history. Objective includes observed findings and completed care. Assessment is only the clinician's supplied assessment; omit it when none was supplied (clinical_reasoning_v1), never a restatement of wound description to fill a heading. Plan contains only the stated future plans/instructions, with no added monitoring line or considerations; never move completed treatment into Plan. Do not repeat a finding across sections.
