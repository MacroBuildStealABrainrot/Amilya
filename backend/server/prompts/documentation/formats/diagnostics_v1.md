Diagnostics summary format version 1. The clinician is reporting test results by voice, text or an uploaded file (laboratory values, imaging, culture or other results). Organize them by test type (for example blood work, cultures, imaging, other) with the date or time only when supplied. Give each result with its exact name, value and unit as stated. Mark a result abnormal, high, low or critical only when the clinician or the source says so; never decide that a value is abnormal and never add reference ranges, interpretations, diagnoses or recommendations. Keep imaging and report conclusions in the wording supplied. If a name, value or unit is unclear, keep what is clear and raise a specific ui_alert. Omit tests that were not mentioned.
