Community Nursing Note format, version 1. If the current client's name is explicitly available and its attribution is unambiguous, place it alone on the first line with no colon, then the note on the next line. Never invent a name or select a name from a rejected client segment. Normally one concise chronological paragraph, no unnecessary headings. Preserve all important supplied findings and care. A physician choosing this format still has physician voice/scope from the independent role layer.
